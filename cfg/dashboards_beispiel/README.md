# Beispiel-Dashboards (kundenneutral)

Standard-Ablage für `paths.dashboards` in `cfg/config.yml`. Liest nur das
Meta-Schema der aktiven Umgebung und dient zum Testen des Frameworks ohne
Kundendaten. Kundendashboards liegen im Kunden-Workspace; dorthin zeigt
`paths.dashboards` im Einsatz.

Format und Platzhalter: `docs/DASHBOARD_KONZEPT.md`, Abschnitt 4.
